## ✦ A New Perspective on Personal Finance

> **Finance shouldn't feel complicated. It should feel empowering.**

BudgetBuddy is an evolving personal finance application that combines financial tracking, interactive analytics, savings management, and a futuristic holographic interface.

Designed with a long-term vision for decentralized finance, BudgetBuddy begins as a local-first financial dashboard and gradually expands toward Web3-powered financial infrastructure.

The mission is simple:

**Understand your money today. Prepare for the financial systems of tomorrow.**

## 📊 Advanced Financial Analytics

### Phase 4A — Implemented

BudgetBuddy transforms recorded transactions into understandable financial information.

#### ◇ Income & Spending

Compare income and expenses using interactive visualizations.

Available historical windows:

`3 Months` · `6 Months` · `12 Months`

Choose between:

- **Latest Activity** — Anchor charts to the most recent recorded transaction.
- **Current Month** — Anchor charts to the current calendar month.

#### ◇ Cash-Flow Intelligence

Track the relationship between income and spending.

```text
NET CASH FLOW
Income - Expenses

CASH-FLOW RATE
(Net Cash Flow / Income) × 100
```

The dashboard also includes:

- Monthly income comparisons.
- Monthly expense comparisons.
- Financial activity summaries.
- Empty-period notices.
- Spending category breakdowns.
- Configured budget utilization.

#### ◇ Spending Breakdown

Discover where recorded expenses are concentrated.

BudgetBuddy identifies:

- Total recorded expenses.
- Largest spending category.
- Category share of expenses.
- Categories exceeding configured limits.
- Spending relative to predefined category budgets.

> Current budget summaries use recorded expenses across all dates. Custom budget configuration is a potential future enhancement.

## 🚀 Getting Started

### Prerequisites

Install:

- Node.js
- npm
- Git
- A code editor such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/SeukallesX/BudgetBuddy.git
```

### 2. Enter the Project

```bash
cd BudgetBuddy
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build the Application

```bash
npm run build
```

A successful build should be verified before deployment.

## 🔐 Data, Privacy & Limitations

BudgetBuddy is currently a development-stage application.

### Local Data Storage

Financial records are stored using browser localStorage.

Current storage keys include:

```text
budgetbuddy-transactions
budgetbuddy-savings-goals
budgetbuddy-goal-contributions
```

### Important Limitations

- Data is stored in the current browser environment.
- Clearing browser storage may remove saved records.
- Data is not currently synchronized across devices.
- localStorage is not an encrypted financial database.
- Wallet connectivity is not yet implemented.
- Savings transfers are simulated.
- AI functionality is currently rule-based.
- Forecasting remains a planned feature.
- The application is not a banking service.

Avoid entering real banking credentials, private keys, seed phrases, or sensitive financial identifiers.
